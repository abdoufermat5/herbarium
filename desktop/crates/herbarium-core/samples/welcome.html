A quick tour

Try it

Where does Herbarium keep your pages?

As ordinary .html files in a folder you own, each with a small .json file holding its title, tags, note and review dates. Back it up or sync it with any tool.

What happens when a page wants the internet?

Nothing, unless you allow it: pages run in a sandbox with network access off. You can turn it on per page with the network switch in the reader.

What does a vitality leaf tell you?

How well you probably still remember that page, from the same forgetting curve the review scheduler uses. A seed means it was never reviewed; wilting means it is past due.

What happens when every page in a reading path is read?

Its tree blossoms. Each page read grows a limb and its leaves; the finished path is marked once, and the grove on Today keeps it on the ground line beside the others.
